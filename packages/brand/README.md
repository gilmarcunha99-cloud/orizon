# Marca Orizon Sports

Fonte única de cores, fontes e logos (derivados do BrandBook Orizon Sports).

- `tokens/tokens.css` e `tokens/tokens.json`: usados pelo site (`apps/web`).
- `tokens/orizon_theme.dart`: tema do app (`apps/mobile/lib/core/theme.dart` é uma cópia ajustada).
- `logo/`: logotipos em SVG (horizontal, símbolo, versões negativas e ícone do app).

Ao mudar uma cor ou fonte aqui, atualize as cópias no site e no app no mesmo pull request.
